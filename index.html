题1: write/scan/sink 文件读写

题目

创建对象 $x = 1{:}100$，用 write 写入文件，删除 $x$ 再读回；用 sink 将 $x$ 写入文件。

知识点

write() 将向量写入文件；scan() 从文件读回向量；sink() 将后续控制台输出重定向到文件。

完整代码
# 方法1: write + scan
x <- 1:100
write(x, file = "x.txt")    # 写入文件
rm(x)                        # 删除对象x
x <- scan("x.txt")           # 从文件读回
x

# 方法2: sink重定向
x <- 1:100
sink("x.txt")     # 开始重定向: 之后所有输出写入文件
print(x)           # 必须用print(), 交互模式下直接写x也可以
sink()             # 关闭重定向, 恢复正常输出
sink() 是"开关"模式：第一次调用开启重定向，第二次调用（无参数）关闭。write() 直接写数据值，sink() 捕获的是 print 输出（带格式）。

第2章 随机变量生成

6题

核心知识点

  • 逆变换法：若 $U \sim U(0,1)$，则 $X = F^{-1}(U)$ 服从CDF为 $F$ 的分布。步骤：①求CDF ②求逆函数 ③生成 $U$ ④计算 $X=F^{-1}(U)$
  • 接受-拒绝法：从易抽样的 $g(x)$ 生成候选值，以概率 $\frac{f(x)}{c\,g(x)}$ 接受。$c = \max_x \frac{f(x)}{g(x)}$。适用于密度已知但CDF难求逆的情况
  • 变换法：利用已知分布间的数学关系。如：若 $Z \sim N(0,1)$，则 $X = e^{\mu + \sigma Z} \sim \text{LN}(\mu, \sigma^2)$
  • 混合分布：先以概率 $p$ 选择成分，再从该成分抽样。如 $p\,N(0,1) + (1-p)\,N(3,1)$
  • 多元正态：$\mathbf{X} = \boldsymbol{\mu} + A\mathbf{Z}$，其中 $\mathbf{Z} \sim N(\mathbf{0}, I)$，$\Sigma = AA^\top$。三种分解：Cholesky、特征值、SVD
Pareto$(a, b)$ 分布
CDF：$F(x) = 1 - \left(\frac{b}{x}\right)^a, \quad x \geq b > 0,\; a > 0$
逆变换：$F^{-1}(u) = b\,(1-u)^{-1/a}$
接受-拒绝法框架
1. 找包络分布 $g(x)$，使得 $f(x) \leq c \cdot g(x)$ 对所有 $x$ 成立
2. 循环：从 $g(x)$ 抽 $Y$，从 $U(0,1)$ 抽 $U$，若 $U \leq \frac{f(Y)}{c\,g(Y)}$ 则接受 $Y$
接受率 $= 1/c$，$c$ 越小效率越高

题1: 逆变换法 - Pareto分布

题目

(1) 推导 $\text{Pareto}(a,b)$ 的逆变换；(2) 生成 $n=1000$ 的 $\text{Pareto}(2,2)$ 样本；(3) 画密度直方图与理论密度对比。

推导过程

$F(x) = 1 - (b/x)^a$，令 $u = F(x)$，解 $x$：

$u = 1 - (b/x)^a \;\Rightarrow\; (b/x)^a = 1-u \;\Rightarrow\; x = b\,(1-u)^{-1/a}$

完整代码
# Pareto分布的逆变换
rpareto <- function(n, a, b) {
  u <- runif(n)
  x <- b * (1 - u)^(-1/a)   # 逆变换公式
  return(x)
}

# 生成Pareto(2,2)样本
set.seed(123)
x <- rpareto(1000, a = 2, b = 2)

# Pareto(2,2)的密度函数: f(x) = a*b^a / x^(a+1)
dpareto <- function(x, a, b) {
  a * b^a / x^(a + 1)
}

# 画密度直方图 + 理论密度曲线
hist(x, breaks = 50, prob = TRUE, xlim = c(2, 20),
     main = "Pareto(2,2) 逆变换法", xlab = "x")
curve(dpareto(x, 2, 2), add = TRUE, col = "red", lwd = 2)

题2: 逆变换法 - 离散分布

题目

(1) 逆变换法生成服从给定分布律的样本；(2) 用 sample 函数；(3) 比较频率与理论概率。

知识点

离散逆变换：计算累积概率 $F(x_k) = \sum_{i \leq k} p_i$，$U$ 落在哪个区间就取哪个值。

完整代码
# 假设分布律: X取0,1,2,3,4, 概率为0.1,0.2,0.2,0.2,0.3
vals <- 0:4
probs <- c(0.1, 0.2, 0.2, 0.2, 0.3)
cp <- cumsum(probs)   # 累积概率: 0.1, 0.3, 0.5, 0.7, 1.0

# (1) 逆变换法
n <- 1000
u <- runif(n)
x1 <- numeric(n)
for (i in 1:n) {
  x1[i] <- vals[min(which(u[i] <= cp))]  # U落在哪个区间
}

# (2) sample函数(更简洁)
x2 <- sample(vals, size = 1000, replace = TRUE, prob = probs)

# (3) 频数表对比
tab1 <- table(x1) / n   # 逆变换法的经验概率
tab2 <- table(x2) / n   # sample的经验概率
cbind(理论概率 = probs, 逆变换法 = as.numeric(tab1), sample法 = as.numeric(tab2))
sample() 是R内置的离散抽样函数，replace=TRUE 表示有放回抽样。考试中优先用 sample()，代码更短。

题3: 接受-拒绝法 - Beta分布

题目

(1) 写接受-拒绝法生成 $\text{Beta}(a,b)$ 样本的R函数；(2) 生成 $\text{Beta}(3,2)$ 样本；(3) 直方图 + 理论密度。

思路

$\text{Beta}(a,b)$ 定义在 $[0,1]$ 上。用均匀分布 $U(0,1)$ 做包络，$g(x)=1$，$c = \max_x f(x) = f(\text{mode})$，其中 $\text{mode} = \frac{a-1}{a+b-2}$（要求 $a,b > 1$）。

完整代码
rbeta_ar <- function(n, a, b) {
  # Beta(a,b)密度: f(x) = x^(a-1)*(1-x)^(b-1) / B(a,b)
  # 包络: g(x)=1 (均匀分布), c = max f(x)

  # 找最大值点: mode = (a-1)/(a+b-2)
  mode_x <- (a - 1) / (a + b - 2)
  c <- dbeta(mode_x, a, b)   # c = f(mode)

  samples <- numeric(n)
  count <- 0
  while (count < n) {
    y <- runif(1)           # 从g(x)=Uniform(0,1)抽候选值
    u <- runif(1)           # 接受概率的随机数
    if (u <= dbeta(y, a, b) / c) {  # 接受条件
      count <- count + 1
      samples[count] <- y
    }
  }
  return(samples)
}

# 生成Beta(3,2)样本
set.seed(123)
x <- rbeta_ar(1000, a = 3, b = 2)

# 直方图 + 理论密度
hist(x, breaks = 30, prob = TRUE, main = "Beta(3,2) 接受-拒绝法")
curve(dbeta(x, 3, 2), add = TRUE, col = "red", lwd = 2)
接受率 $= 1/c$。$c$ 越大，拒绝越多，效率越低。选好的包络分布很重要！

rlnorm_trans <- function(n, mu, sigma) {

题5: 混合正态分布

题目

生成1000个服从 $p\,N(0,1) + (1-p)\,N(3,1)$ 的样本，$p = 0.1, 0.3, 0.5, 0.7, 0.9$。

思路

混合分布 = 先掷"硬币"选成分，再从该成分抽样。

完整代码
rmix <- function(n, p) {
  # 每个样本: 以概率p从N(0,1)抽, 以概率1-p从N(3,1)抽
  k <- rbinom(n, 1, p)         # k=1选N(0,1), k=0选N(3,1)
  x <- ifelse(k == 1, rnorm(n, 0, 1), rnorm(n, 3, 1))
  return(x)
}

# 对不同p值画密度图
par(mfrow = c(2, 3))  # 2行3列子图
for (p in c(0.1, 0.3, 0.5, 0.7, 0.9)) {
  set.seed(123)
  x <- rmix(1000, p)
  hist(x, breaks = 30, prob = TRUE, main = paste("p =", p))
  # 叠加理论密度
  curve(p * dnorm(x, 0, 1) + (1 - p) * dnorm(x, 3, 1),
        add = TRUE, col = "red", lwd = 2)
}
rbinom(n, 1, p) 生成 $n$ 个0/1值，概率 $p$ 取1 —— 这是选择成分的"硬币"。混合分布在 $p$ 接近0.5时可能呈现双峰。

题6: 多元正态分布 - 三种分解法（函数封装风格）

题目

用 Cholesky / 特征值 / SVD 三种方法封装为独立函数 rmvn.eigen / rmvn.svd / rmvn.choleski，生成 200 个三维多元正态样本，$\boldsymbol{\mu} = (0,1,2)^\top$，给定协方差矩阵 $\Sigma$。

核心公式

$\mathbf{X} = \boldsymbol{\mu} + \mathbf{Z}\,R$，其中 $\mathbf{Z} \sim N(\mathbf{0}, I)$，$R$ 由 $\Sigma$ 分解得到（满足 $R^\top R = \Sigma$ 或 $RR^\top = \Sigma$，具体形式因方法而异）。

完整代码
set.seed(134)
n <- 200
mu <- c(0, 1, 2)
data <- c(1.0, -0.5,  0.5,
         -0.5,  1.0, -0.5,
          0.5, -0.5,  1.0)
Sigma <- matrix(data, 3, 3, byrow = TRUE)

# === 方法1: 特征值分解 ===
rmvn.eigen <- function(n, mu, Sigma) {
  d <- length(mu)
  ev <- eigen(Sigma, symmetric = TRUE)
  lambda <- ev$values
  V <- ev$vectors
  R <- V %*% diag(sqrt(lambda)) %*% t(V)        # Σ^{1/2}
  Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
  X <- Z %*% R + matrix(mu, n, d, byrow = TRUE)
  return(X)
}

# === 方法2: SVD分解 ===
rmvn.svd <- function(n, mu, Sigma) {
  d <- length(mu)
  S <- svd(Sigma)
  R <- S$u %*% diag(sqrt(S$d)) %*% t(S$v)
  Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
  X <- Z %*% R + matrix(mu, n, d, byrow = TRUE)
  return(X)
}

# === 方法3: Cholesky分解 ===
rmvn.choleski <- function(n, mu, Sigma) {
  d <- length(mu)
  Q <- chol(Sigma)                               # Σ = Q'Q (Q 上三角)
  Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
  X <- Z %*% Q + matrix(mu, n, d, byrow = TRUE)
  return(X)
}

ans_eigen    <- rmvn.eigen(n, mu, Sigma)
ans_svd      <- rmvn.svd(n, mu, Sigma)
ans_choleski <- rmvn.choleski(n, mu, Sigma)

# 画散点图矩阵对比
pairs(ans_eigen,    main = "特征值分解")
pairs(ans_svd,      main = "SVD分解")
pairs(ans_choleski, main = "Cholesky分解")
三种分解本质都是找 $R$ 使 $\mathbf{Z}R$ 的协方差等于 $\Sigma$：
- 特征值/SVD：$R = V\sqrt{\Lambda}V^\top$（对称矩阵 $\Sigma^{1/2}$，最直观）
- Cholesky：$R = Q$（上三角），chol() 返回上三角 $Q$ 满足 $\Sigma = Q^\top Q$ — 最快，要求 $\Sigma$ 正定

第3章 蒙特卡罗积分

4题

核心知识点

  • 基本MC积分：$\theta = \int h(x)\,dx \approx \frac{1}{n}\sum g(X_i)$，本质是用样本均值估计期望
  • 简单MC：$\int_a^b h(x)\,dx = (b-a)\,E[h(X)]$，$X \sim U(a,b)$。估计：$\hat\theta = \frac{b-a}{n}\sum_{i=1}^n h(X_i)$
  • 对偶变量法(Antithetic)：用 $U$ 和 $1-U$（对偶）的均值来降低方差。$\hat\theta = \frac{1}{n}\sum \frac{g(U_i)+g(1-U_i)}{2}$
  • 重要抽样法(Importance Sampling)：$\int h(x)f(x)\,dx = \int \frac{h(x)f(x)}{g(x)}\,g(x)\,dx$，从 $g(x)$ 抽样。估计：$\hat\theta = \frac{1}{n}\sum \frac{h(X_i)f(X_i)}{g(X_i)}$
  • 方差估计：$\widehat{\text{Var}}(\hat\theta) = S^2 / n$，$S^2$ 是样本方差
MC积分的核心恒等式
$$\int_a^b h(x)\,dx = (b-a)\,E_U[h(U)], \quad U \sim \text{Uniform}(a,b)$$ 更一般：$\int h(x)f(x)\,dx = E_f[h(X)] \approx \frac{1}{n}\sum_{i=1}^n h(X_i),\; X_i \sim f$

题1: 基本MC积分 - $\int_0^{0.5} e^{-x}\,dx$

题目

估计 $\theta = \int_0^{0.5} e^{-x}\,dx$。(1) 均匀分布抽样；(2) 指数分布 + 指示函数法；(3) 比较两种方法的方差。

理论值

$\theta = [-e^{-x}]_0^{0.5} = 1 - e^{-0.5} \approx 0.3935$

完整代码
set.seed(123)
n <- 10000

# (1) 均匀分布 U(0, 0.5) 抽样
# θ = ∫_0^{0.5} e^{-x} dx = 0.5 * E[e^{-U}], U ~ U(0, 0.5)
x <- runif(n, 0, 0.5)
h <- function(x) 0.5 * exp(-x)
y <- h(x)
theta_hat <- mean(y)
var_hat   <- var(y) / n
print(c(theta_hat, var_hat))

# (2) 指数分布 + 指示函数法 (hit-or-miss)
# θ = P(0 < X < 0.5), X ~ Exp(1) (因为Exp(1)密度恰为e^{-x})
x <- rexp(n)
y <- as.numeric(x > 0 & x < 0.5)   # 落入[0,0.5]的指示
theta_delta <- mean(y)
var_delta   <- var(y) / n
print(c(theta_delta, var_delta))

# (3) 方差对比
data.frame(
  "方法" = c("均匀抽样", "指数+指示函数"),
  "估计" = c(theta_hat, theta_delta),
  "方差" = c(var_hat,   var_delta)
)
# 结论: 均匀抽样的方差更小 (前者 var ≈ 6.3e-6, 后者 ≈ 2.4e-5)
# 原因: 指示函数是0/1变量, 方差由Bernoulli决定;
#       而均匀法直接对光滑函数取均值, 方差更小
关键对比：指数+指示函数法本质是 hit-or-miss MC（伯努利方差 $p(1-p)/n$），通常比直接连续型估计方差大。当抽样密度 $g(x)$ 越贴合 $h(x)$ 形状，方差越小。

题2: MC估计正态分布CDF $\Phi(x)$

题目

(1) 用MC估计 $\Phi(x)$；(2) 与 pnorm 比较；(3) 估计 $\Phi(2)$ 及其方差。

思路

对 $x > 0$：$\Phi(x) = 0.5 + \int_0^x \varphi(t)\,dt = 0.5 + x\,E[\varphi(xU)]$，$U \sim U(0,1)$，$\varphi$ 为标准正态密度。

完整代码
phi_mc <- function(x, n = 10000) {
  # Φ(x) = 0.5 + ∫_0^x φ(t)dt = 0.5 + x * E[φ(xU)], U ~ U(0,1)
  u <- runif(n)
  g <- dnorm(x * u)           # φ(x*u)
  theta <- x * mean(g)         # ∫_0^x φ(t)dt 的MC估计
  return(0.5 + theta)
}

# (2) 与pnorm比较
x_vals <- seq(0.5, 3, by = 0.5)
mc_vals <- sapply(x_vals, phi_mc)
true_vals <- pnorm(x_vals)
cbind(x = x_vals, MC = round(mc_vals, 4), pnorm = round(true_vals, 4))

# (3) Φ(2)的MC估计和方差
set.seed(123)
n <- 10000
u <- runif(n)
g <- 2 * dnorm(2 * u)         # x=2时的被积函数值
theta <- 0.5 + mean(g)
var_theta <- var(g) / n
cat("Φ(2) MC估计:", theta, "\n")
cat("方差:", var_theta, "\n")
cat("pnorm(2):", pnorm(2), "\n")

题3: 对偶变量法 (Antithetic Variates)

题目

用对偶变量法估计 $\int_0^1 \frac{e^{-x}}{1+x^2}\,dx$，并计算方差。

核心思想

若 $g(x)$ 单调，则 $g(U)$ 和 $g(1-U)$ 负相关，$\frac{g(U)+g(1-U)}{2}$ 的方差 $<$ $g(U)$ 的方差。

完整代码
n <- 10000
set.seed(123)

h <- function(x) exp(-x) / (1 + x^2)

# 普通MC
u <- runif(n)
theta_mc <- mean(h(u))
var_mc <- var(h(u)) / n

# 对偶变量法
u <- runif(n / 2)                           # 只需n/2个
theta_anti <- mean((h(u) + h(1 - u)) / 2)  # 对偶均值
var_anti <- var((h(u) + h(1 - u)) / 2) / (n / 2)

cat("普通MC:   theta =", theta_mc,   ", var =", var_mc, "\n")
cat("对偶变量: theta =", theta_anti, ", var =", var_anti, "\n")
cat("方差缩减比:", var_mc / var_anti, "\n")
对偶变量法只需一半样本量！关键：用 $U$ 和 $1-U$ 配对。适用于被积函数单调或近似单调的情况。

题4: 重要抽样法 (Importance Sampling)

题目

用重要抽样法估计 $\int_1^{+\infty} \frac{x^2}{\sqrt{2\pi}}\,e^{-x^2/2}\,dx$。

思路

被积函数 $= x^2 \varphi(x)$，积分域 $[1,+\infty)$。选 $g(x)$ 为平移指数分布：$g(x) = e^{-(x-1)}$，$x \geq 1$。从 $g$ 抽样：$Y = 1 + \text{Exp}(1)$。

完整代码
n <- 10000
set.seed(123)

# 目标: ∫_1^∞ x² · φ(x) dx, φ(x) = dnorm(x)
# 重要性函数 g(x) = e^{-(x-1)}, x ≥ 1
# 从g抽样: Y = 1 + rexp(n, 1)

y <- 1 + rexp(n, 1)    # 从g(x)抽样, x ≥ 1

# 重要抽样: θ = E_g[h(Y)·f(Y)/g(Y)]
# 其中 f(Y) = Y² · dnorm(Y), g(Y) = exp(-(Y-1))
w <- y^2 * dnorm(y) / exp(-(y - 1))

theta <- mean(w)
var_theta <- var(w) / n
cat("重要抽样估计:", theta, "\n")
cat("方差:", var_theta, "\n")

# 验证: 理论值
true_val <- integrate(function(x) x^2 * dnorm(x), 1, Inf)$value
cat("理论值:", true_val, "\n")
重要抽样的关键：选 $g(x)$ 使得 $f(x)/g(x)$ 尽可能平坦（接近常数），这样方差最小。
常见的 $g(x)$ 选择：截断正态、指数分布、$t$ 分布（尾部更厚）。

第4章 蒙特卡罗推断（假设检验与置信区间）

4题

核心知识点

  • MC模拟验证统计方法：重复模拟大量样本，检查置信区间覆盖率 / 检验犯错概率是否达标
  • 截尾均值 (Trimmed Mean)：去掉最大/最小各 $k$ 个观测后的均值。对离群值稳健
  • 均方误差MSE：$\text{MSE}(\hat\theta) = E[(\hat\theta - \theta)^2] = \text{Var}(\hat\theta) + \text{Bias}^2$。MC估计：$\widehat{\text{MSE}} = \frac{1}{M}\sum_{i=1}^M (\hat\theta_i - \theta)^2$
  • 置信区间覆盖率：模拟 $M$ 次，统计 $\theta$ 落在CI中的比例。应 $\approx 1-\alpha$
  • 假设检验的功效 (Power)：$\text{Power} = P(\text{拒绝}H_0 \mid H_1\text{为真})$。MC模拟：从 $H_1$ 下生成数据，统计拒绝比例
  • 第一类错误 (Type I error)：$P(\text{拒绝}H_0 \mid H_0\text{为真})$，应 $\approx \alpha$
正态总体置信区间
$\mu$ 的CI（$\sigma^2$ 未知）：$\bar X \pm t_{\alpha/2,\,n-1} \cdot \frac{S}{\sqrt{n}}$
对数正态 $\text{LN}(\mu,\sigma^2)$：先取对数 $Y = \ln X \sim N(\mu,\sigma^2)$，对 $Y$ 构造 $t$ 区间
Poisson 参数 $\lambda$ 的近似CI
大样本：$\bar X \pm z_{\alpha/2} \cdot \sqrt{\bar X / n}$，其中 $\bar X$ 是样本均值

题1: MC估计截尾均值的MSE - Cauchy分布

题目

$X_1, \ldots, X_{20}$ 来自标准Cauchy分布，估计截尾均值 $\bar X_{[-k]}$ 在 $k=1,\ldots,9$ 时的MSE。

知识点

Cauchy分布没有有限均值，所以普通均值不好用。截尾均值更稳健。标准Cauchy的中位数 $= 0$（即location参数）。

完整代码
n <- 20
M <- 10000  # MC模拟次数
theta <- 0  # Cauchy(0,1)的location参数=0

mse <- numeric(9)
for (k in 1:9) {
  tmeans <- numeric(M)
  for (i in 1:M) {
    x <- rcauchy(n, location = 0, scale = 1)
    x_sorted <- sort(x)
    # 截尾均值: 去掉最小k个和最大k个
    tmeans[i] <- mean(x_sorted[(k + 1):(n - k)])
  }
  mse[k] <- mean((tmeans - theta)^2)  # MSE = E[(θ̂-θ)²]
}

# 结果
data.frame(k = 1:9, MSE = round(mse, 4))
plot(1:9, mse, type = "b", xlab = "k", ylab = "MSE",
     main = "截尾均值的MSE vs k")

# 结论: MSE在某个k处最小(通常k=5~7附近)
# 截尾比例越大越稳健, 但损失效率
也可以用 mean(x, trim = k/n) 来计算截尾均值，trim 参数是截尾比例（0到0.5）。

题2: MC验证置信区间 - 对数正态分布

题目

(1) 构造 $\text{LN}(\mu,\sigma^2)$ 中参数 $\mu$ 的 $1-\alpha$ 置信区间；(2) MC模拟验证覆盖率。

推导

$X \sim \text{LN}(\mu,\sigma^2) \;\Rightarrow\; Y = \ln X \sim N(\mu,\sigma^2)$。对 $Y$ 用 $t$ 区间：$\bar Y \pm t_{\alpha/2,\,n-1} \cdot \frac{S_Y}{\sqrt{n}}$

完整代码
n <- 20; mu <- 0; sigma <- 1; alpha <- 0.05
M <- 10000

# MC验证覆盖率
count <- 0
for (i in 1:M) {
  x <- rlnorm(n, meanlog = mu, sdlog = sigma)
  y <- log(x)                # 取对数变成正态
  ybar <- mean(y)
  s <- sd(y)
  t_crit <- qt(1 - alpha/2, df = n - 1)
  lower <- ybar - t_crit * s / sqrt(n)
  upper <- ybar + t_crit * s / sqrt(n)
  if (lower <= mu && mu <= upper) count <- count + 1
}

coverage <- count / M
cat("经验覆盖率:", coverage, "\n")
cat("名义水平:", 1 - alpha, "\n")
# 覆盖率应接近0.95

题3: MC验证置信区间 - Poisson分布（务必用Z检验）

题目

(1) 构造 $\text{Poisson}(\lambda)$ 的近似CI；(2) MC验证经验覆盖率。设 $n=1000,\;\lambda=6,\;\alpha=0.05$。

推导

由 CLT：$\sqrt{n}(\bar X - \lambda) \;\dot\to\; N(0,\lambda)$，故 $\bar X \;\dot\sim\; N\!\left(\lambda,\,\frac{\lambda}{n}\right)$，CI 用 Z 临界值：$\bar X \pm z_{\alpha/2}\sqrt{\bar X / n}$

完整代码
set.seed(7789)
n <- 1000; lambda <- 6; alpha <- 0.05
m <- 1000

ci.maker <- function(y) {
  y_bar <- mean(y)
  z <- qnorm(1 - alpha/2)     # ✓ 用 Z 临界值, 不是 qt!
  lower <- y_bar - z * sqrt(y_bar / n)
  upper <- y_bar + z * sqrt(y_bar / n)
  list(y_bar = y_bar, lower = lower, upper = upper)
}

cnt <- 0
for (i in 1:m) {
  x <- rpois(n, lambda = lambda)
  res <- ci.maker(x)
  if (lambda > res$lower && lambda < res$upper) cnt <- cnt + 1
}
coverage <- cnt / m
print(coverage)   # 接近 0.95
常见错误纠正：有些参考答案用 qt(1-alpha/2, df=n-1) 构造 Poisson 的 CI，这是错误的！
- Poisson 的渐近正态来自 CLT，参数已知为 $\sqrt{\lambda/n}$，不涉及对方差的 $t$ 自由度修正
- 只有"正态总体均值 + 方差未知"时才用 $t$ 检验
- $n$ 大时 $t \to z$ 二者数值差异极小，但写法上必须用 qnorm

题4: MC计算 $t$ 检验的功效 (Power)

题目

$X_1,\ldots,X_{20} \sim N(\mu, \sigma^2)$，$\sigma=2$ 已知（此处仍演示 $t$ 检验框架，方差由样本估计）。检验 $H_0{:}\;\mu=500$ vs $H_1{:}\;\mu \neq 500$。MC计算 (1) 经验第一类错误率；(2) 在 $\mu \in \{494,498,502,506\}$ 下的功效。

完整代码
set.seed(7789)
n <- 20; alpha <- 0.05; m <- 1000
mu_0 <- 500; sd <- 2

# (1) 第一类错误率 (H0: μ=500下模拟)
cnt <- 0
for (i in 1:m) {
  x <- rnorm(n, mean = mu_0, sd = sd)
  x_bar <- mean(x); x_sd <- sd(x)
  t_crit <- qt(1 - alpha/2, df = n - 1)
  lower <- x_bar - t_crit * x_sd / sqrt(n)
  upper <- x_bar + t_crit * x_sd / sqrt(n)
  if (mu_0 > lower && mu_0 < upper) cnt <- cnt + 1   # 落在CI中=不拒绝
}
type1 <- 1 - cnt / m
print(type1)   # 应接近 alpha = 0.05

# (2) 功效 (在各H1: μ=备择值下模拟)
mus <- c(494, 498, 502, 506)
power <- numeric(length(mus))
for (i in seq_along(mus)) {
  mu <- mus[i]; cnt <- 0
  for (j in 1:m) {
    x <- rnorm(n, mean = mu, sd = sd)
    x_bar <- mean(x); x_sd <- sd(x)
    t_crit <- qt(1 - alpha/2, df = n - 1)
    lower <- x_bar - t_crit * x_sd / sqrt(n)
    upper <- x_bar + t_crit * x_sd / sqrt(n)
    if (mu_0 < lower | mu_0 > upper) cnt <- cnt + 1   # H0被拒绝
  }
  power[i] <- cnt / m
}
print(power)

# 功效曲线
plot(mus, power, type = "b", xlab = "真实μ", ylab = "Power",
     main = "t检验功效曲线")
abline(h = alpha, lty = 2, col = "red")
功效 (Power) $= P(\text{拒绝}H_0 \mid H_1\text{为真})$。$\mu$ 离 500 越远，power 越高。
第一类错误率 $= P(\text{拒绝}H_0 \mid H_0\text{为真})$，应控制在 $\alpha$ 附近。
Z vs t 选择：$\sigma$ 已知 → Z 检验；$\sigma$ 未知 → t 检验。

第5章 Bootstrap与Jackknife

3题

核心知识点

  • Jackknife：逐一去掉第 $i$ 个观测，计算"留一"统计量 $\hat\theta_{(i)}$。用于估计偏差和标准差
  • Jackknife偏差：$\widehat{\text{bias}}_{\text{jack}} = (n-1)(\bar\theta_{(\cdot)} - \hat\theta)$，其中 $\bar\theta_{(\cdot)} = \frac{1}{n}\sum \hat\theta_{(i)}$
  • Jackknife标准差：$\widehat{\text{se}}_{\text{jack}} = \sqrt{\frac{n-1}{n}\sum_{i=1}^n (\hat\theta_{(i)} - \bar\theta_{(\cdot)})^2}$
  • Bootstrap：从原样本有放回抽样 $B$ 次，每次算统计量。用 $B$ 个统计量估计分布
  • Bootstrap偏差：$\widehat{\text{bias}}_{\text{boot}} = \bar\theta^* - \hat\theta$（Bootstrap均值 - 原始估计）
  • Bootstrap CI：
    - 标准正态：$\hat\theta \pm z_{\alpha/2} \cdot \widehat{\text{se}}_{\text{boot}}$
    - 基本 (Basic)：$(2\hat\theta - \theta^*_{1-\alpha/2},\; 2\hat\theta - \theta^*_{\alpha/2})$
    - 百分位数 (Percentile)：$(\theta^*_{\alpha/2},\; \theta^*_{1-\alpha/2})$
    - Bootstrap-$t$：$\hat\theta - t^*_{1-\alpha/2}\cdot\widehat{\text{se}},\;\hat\theta - t^*_{\alpha/2}\cdot\widehat{\text{se}}$（需嵌套Bootstrap估计se）
Jackknife公式速查
偏差：$\widehat{\text{bias}} = (n-1)(\bar\theta_{(\cdot)} - \hat\theta)$
标准差：$\widehat{\text{se}} = \sqrt{\frac{n-1}{n}\sum_{i=1}^n (\hat\theta_{(i)} - \bar\theta_{(\cdot)})^2}$
其中 $\hat\theta_{(i)}$ 是去掉第 $i$ 个后的估计，$\bar\theta_{(\cdot)} = \frac{1}{n}\sum \hat\theta_{(i)}$
Bootstrap 公式速查（重点补充）
设原样本 $\hat\theta$，对样本有放回抽 $B$ 次得到 $\hat\theta^*_1,\ldots,\hat\theta^*_B$，记 $\bar\theta^* = \frac{1}{B}\sum_{b=1}^B \hat\theta^*_b$。

Bootstrap 偏差：$\widehat{\text{bias}}_{\text{boot}} = \bar\theta^* - \hat\theta$

Bootstrap 标准误 (SE)： $$\widehat{\text{se}}_{\text{boot}} = \sqrt{\frac{1}{B-1}\sum_{b=1}^B \left(\hat\theta^*_b - \bar\theta^*\right)^2} = \text{sd}(\hat\theta^*_{1:B})$$ 即直接对 $B$ 个 bootstrap 重复估计取样本标准差，R 中 sd(theta_boot) 即可。

三种 Bootstrap CI（置信度 $1-\alpha$，$\theta^*_q$ 表示 bootstrap 分布的 $q$ 分位数）：
  • 标准正态：$\hat\theta \pm z_{1-\alpha/2}\cdot\widehat{\text{se}}_{\text{boot}}$
  • 百分位数：$(\theta^*_{\alpha/2},\;\theta^*_{1-\alpha/2})$
  • 基本 (Basic)：$(2\hat\theta - \theta^*_{1-\alpha/2},\;2\hat\theta - \theta^*_{\alpha/2})$
▶

题2: Bootstrap $t$ 置信区间 - 相关系数（封装函数风格）

题目

对相关系数 $\hat\rho$ 给出 Bootstrap-$t$ 置信区间，封装为通用函数 boot.t.ci(x, B, R, level, statistic)。

思路

Bootstrap-$t$ 需要：外层 Bootstrap 算 $\theta^*_b$，内层嵌套 Bootstrap 算 $\widehat{\text{se}}^*_b$。构造 $t^*_b = \frac{\theta^*_b - \hat\theta}{\widehat{\text{se}}^*_b}$，再用其分位数倒推 CI。

完整代码
library(bootstrap)
set.seed(1234)
data(law)

# === 通用 boot.t.ci 函数 ===
boot.t.ci <- function(x, B = 500, R = 100, level = 0.95, statistic) {
  x <- as.matrix(x)
  n <- nrow(x)
  stat <- rep(0, B)
  se   <- rep(0, B)

  # 内层 Bootstrap: 估计单个样本的 SE
  boot.se <- function(x, R, f) {
    x <- as.matrix(x); m <- nrow(x)
    th <- replicate(R, expr = {
      i <- sample(1:m, size = m, replace = TRUE)
      f(x[i, ])
    })
    return(sd(th))
  }

  # 外层 Bootstrap
  for (b in 1:B) {
    j <- sample(1:n, size = n, replace = TRUE)
    y <- x[j, ]
    stat[b] <- statistic(y)
    se[b]   <- boot.se(y, R = R, f = statistic)
  }

  stat0 <- statistic(x)
  se0   <- sd(stat)
  t.stats <- (stat - stat0) / se
  alpha <- 1 - level
  Qt <- quantile(t.stats, c(alpha / 2, 1 - alpha / 2), type = 1)
  names(Qt) <- rev(names(Qt))
  CI <- rev(stat0 - Qt * se0)
  return(CI)
}

# === 应用：相关系数的 Bootstrap-t CI ===
x <- cbind(law$LSAT, law$GPA)
func_stat <- function(x) cor(x[, 1], x[, 2])

ci <- boot.t.ci(x, B = 2000, R = 200, statistic = func_stat)
print(ci)
注意 Bootstrap-$t$ CI 公式中上下分位数是反过来的（代码里用 rev() 实现）：下界用 $t^*_{1-\alpha/2}$，上界用 $t^*_{\alpha/2}$。
boot.t.ci 设计为通用接口：传入数据矩阵 x 与统计量函数 statistic 即可。适用于任意标量统计量（均值、相关、回归系数等）。

题3: Bootstrap估计 - 指数分布故障率

题目

空调故障间隔数据，假设 $\sim \text{Exp}(\lambda)$。(1) $\lambda$ 的MLE；(2) Bootstrap偏差和标准差；(3) $1/\lambda$ 的三种Bootstrap CI。

知识点

$\text{Exp}(\lambda)$ 的MLE：$\hat\lambda = 1/\bar X$。故障间隔均值 $= 1/\lambda$。

完整代码
library(boot)
data(aircondit)
x <- aircondit$hours
n <- length(x)    # n=12

# (1) MLE
lambda_hat <- 1 / mean(x)
cat("λ的MLE:", lambda_hat, "\n")
cat("1/λ的MLE (均值):", mean(x), "\n")

# (2) Bootstrap偏差和标准差
B <- 10000
lambda_boot <- numeric(B)
for (b in 1:B) {
  x_b <- sample(x, n, replace = TRUE)
  lambda_boot[b] <- 1 / mean(x_b)
}
bias_boot <- mean(lambda_boot) - lambda_hat
se_boot <- sd(lambda_boot)
cat("Bootstrap偏差:", bias_boot, "\n")
cat("Bootstrap标准差:", se_boot, "\n")

mean_boot <- numeric(B)
for (b in 1:B) {
  x_b <- sample(x, n, replace = TRUE)
  mean_boot[b] <- mean(x_b)
}

ci_norm <- c(mean_hat - z * sd(mean_boot), mean_hat + z * sd(mean_boot))

# 基本CI (Basic): (2θ̂ - θ*_{0.975}, 2θ̂ - θ*_{0.025})
ci_basic <- c(2 * mean_hat - quantile(mean_boot, 0.975),
              2 * mean_hat - quantile(mean_boot, 0.025))

cat("标准正态CI:", ci_norm, "\n")
cat("百分位数CI:", ci_perc, "\n")
cat("基本CI:", ci_basic, "\n")

- 标准正态：$\hat\theta \pm z \cdot \text{se}$ — 最简单，假设对称
- 百分位数：直接取Bootstrap分位数 — 直观，自动处理偏斜
- 基本 (Basic)：$2\hat\theta - \theta^*$ 分位数 — 对偏差做镜像修正

题目

完整代码
f <- function(x) x^3 - 2*x - 5

# (1) 手写二分法
bisection <- function(f, a, b, tol = 1e-8, maxiter = 1000) {
  for (i in 1:maxiter) {
    mid <- (a + b) / 2
    if (abs(f(mid)) < tol || (b - a) / 2 < tol) {
      return(list(root = mid, iter = i))
    }
    if (f(a) * f(mid) < 0) {
      b <- mid        # 根在左半区间
    } else {
      a <- mid        # 根在右半区间
    }
  }
  return(list(root = mid, iter = maxiter))
}

f_double <- function(x) -2          # 二阶导

newton_opt <- function(x0, tol = 1e-8, maxiter = 100) {
  x <- x0
  for (i in 1:maxiter) {
    x_new <- x - f_prime(x) / f_double(x)  # Newton迭代
    if (abs(x_new - x) < tol) {

    }
    x <- x_new
  }

}

第7章 MCMC方法 (Markov Chain Monte Carlo)

3题

核心知识点

  • Metropolis-Hastings (MH) 算法：从目标分布 $f(x)$ 抽样的通用方法。核心：提议 + 接受/拒绝
  • MH步骤：①从提议分布 $g(Y|X_t)$ 生成候选 $Y$；②计算接受概率 $\alpha(X_t,Y) = \min\!\left\{1,\;\frac{f(Y)\,g(X_t|Y)}{f(X_t)\,g(Y|X_t)}\right\}$；③以概率 $\alpha$ 接受 $Y$，否则 $X_{t+1}=X_t$
  • Metropolis算法：MH特例，要求 $g(Y|X) = g(X|Y)$（对称提议）。此时 $\alpha = \min\!\left\{1,\;\frac{f(Y)}{f(X_t)}\right\}$
  • 独立抽样 (Independence Sampler)：提议分布 $g(Y)$ 不依赖当前状态。$\alpha = \min\!\left\{1,\;\frac{f(Y)\,g(X_t)}{f(X_t)\,g(Y)}\right\}$
  • Burn-in：丢弃链初始部分（还未到达平稳分布）。通常丢弃前10%-50%
  • 链的诊断：看 trace plot（轨迹图），接受率（理想20%-50%），自相关图
MH接受概率
一般MH：$\alpha(X,Y) = \min\!\left\{1,\;\dfrac{f(Y)\,g(X|Y)}{f(X)\,g(Y|X)}\right\}$

对称提议 (Metropolis)：$\alpha(X,Y) = \min\!\left\{1,\;\dfrac{f(Y)}{f(X)}\right\}$

独立抽样：$\alpha(X,Y) = \min\!\left\{1,\;\dfrac{f(Y)\,g(X)}{f(X)\,g(Y)}\right\}$
Rayleigh分布
$$f(x;\sigma) = \frac{x}{\sigma^2}\,\exp\!\left(-\frac{x^2}{2\sigma^2}\right), \quad x \geq 0$$

完整代码
set.seed(13)

# (1) 通用框架: 先决定每组样本量, 再分别抽样, 最后打乱
rmmvn.eigen <- function(n, p, mu1, Sigma1, mu2, Sigma2) {
  rmvn.eigen <- function(n, mu, Sigma) {
    d <- length(mu)
    ev <- eigen(Sigma, symmetric = TRUE)
    R  <- ev$vectors %*% diag(sqrt(ev$values)) %*% t(ev$vectors)
    Z  <- matrix(rnorm(n * d), nrow = n, ncol = d)
    Z %*% R + matrix(mu, n, d, byrow = TRUE)
  }
  n1 <- rbinom(1, size = n, prob = p); n2 <- n - n1
  X <- rbind(rmvn.eigen(n1, mu1, Sigma1), rmvn.eigen(n2, mu2, Sigma2))
  X[sample(1:n), ]
}

rmmvn.svd <- function(n, p, mu1, Sigma1, mu2, Sigma2) {
  rmvn.svd <- function(n, mu, Sigma) {
    d <- length(mu); S <- svd(Sigma)
    R <- S$u %*% diag(sqrt(S$d)) %*% t(S$v)
    Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
    Z %*% R + matrix(mu, n, d, byrow = TRUE)
  }
  n1 <- rbinom(1, size = n, prob = p); n2 <- n - n1
  X <- rbind(rmvn.svd(n1, mu1, Sigma1), rmvn.svd(n2, mu2, Sigma2))
  X[sample(1:n), ]
}

rmmvn.choleski <- function(n, p, mu1, Sigma1, mu2, Sigma2) {
  rmvn.choleski <- function(n, mu, Sigma) {
    d <- length(mu); Q <- chol(Sigma)
    Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
    Z %*% Q + matrix(mu, n, d, byrow = TRUE)
  }
  n1 <- rbinom(1, size = n, prob = p); n2 <- n - n1
  X <- rbind(rmvn.choleski(n1, mu1, Sigma1), rmvn.choleski(n2, mu2, Sigma2))
  X[sample(1:n), ]
}

- $\sigma$ 已知 → Z 检验：$T = \sqrt{n}(\bar X-\mu_0)/\sigma$，临界值 $z_{\alpha/2}$

附加题 (Ch6): Cauchy 位置参数的 Newton-Raphson MLE

题目

$X_1,\ldots,X_n$ 来自 $\text{Cauchy}(\mu, 1)$，$\mu=2,\;n=200$。用 Newton 法求 $\mu$ 的 MLE，初始 $\mu^{(0)}=1$。

推导

对数似然 $\ell(\mu) = -\sum_i \ln(1+(x_i-\mu)^2)$。Newton 迭代：$\mu^{(k+1)} = \mu^{(k)} - \dfrac{\ell'(\mu^{(k)})}{\ell''(\mu^{(k)})}$。一/二阶导见上方公式。

完整代码
set.seed(13)
n <- 200; mu <- 2
x <- rcauchy(n, location = mu, scale = 1)

nt <- function(mu0, eps = 1e-6, iter.max = 200) {
  f_prime  <- function(mu) sum(2 * (x - mu) / (1 + (x - mu)^2))
  f_double <- function(mu) sum(2 * ((x - mu)^2 - 1) / (1 + (x - mu)^2)^2)
  it <- 0
  for (i in 1:iter.max) {
    it <- it + 1
    mu1 <- mu0 - f_prime(mu0) / f_double(mu0)
    if (abs(mu1 - mu0) < eps) break
    mu0 <- mu1
  }
  list(root = mu1, iter = it)
}

res <- nt(mu0 = 1)
print(res)   # root 应接近真值 μ=2
Cauchy MLE 易错点：
- Cauchy 似然非凸、可能多个局部极大 → 初值选择影响收敛
- 不能用样本均值做初值（Cauchy 均值不存在），用样本中位数更稳健
- Newton 法在二阶导接近 0 时不稳定，可加阻尼或退回到二分法

bootstrap_ci_manual <- function(x, stat, B = 2000, conf = 0.95, seed = NULL) {
  theta0 <- stat(as.matrix(x))

bootstrap_t_ci <- function(x, stat, B = 500, R = 100, conf = 0.95, seed = NULL) {
  if (!is.null(seed)) set.seed(seed)
  x <- as.matrix(x); n <- nrow(x); theta0 <- stat(x)
  stat_b <- se_b <- numeric(B)
  boot_se <- function(z) sd(bootstrap_reps(z, stat, R))
  for (b in 1:B) {
    ind <- sample.int(n, size = n, replace = TRUE)
    xb <- x[ind, , drop = FALSE]
    stat_b[b] <- stat(xb); se_b[b] <- boot_se(xb)
  }
  se0 <- sd(stat_b)
  tstat <- (stat_b - theta0) / se_b
  alpha <- 1 - conf
  q <- as.numeric(quantile(tstat, c(alpha / 2, 1 - alpha / 2), type = 1))
  c(lower = theta0 - q[2] * se0, upper = theta0 - q[1] * se0)
}

jackknife_se_bias <- function(x, stat) {

mh_independence <- function(n, target, rprop, dprop, x0, seed = NULL) {
  if (!is.null(seed)) set.seed(seed)
  x <- numeric(n); x[1] <- x0; reject <- 0
  for (i in 2:n) {
    y <- rprop(1)
    ratio <- target(y) * dprop(x[i - 1]) / (target(x[i - 1]) * dprop(y))
    if (runif(1) <= min(1, ratio)) x[i] <- y
    else { x[i] <- x[i - 1]; reject <- reject + 1 }
  }
  list(chain = x, reject_rate = reject / (n - 1))
}

bisection_solve <- function(f, lower, upper, tol = 1e-8, max_iter = 1000) {
  fl <- f(lower); fu <- f(upper)
  if (fl * fu > 0) stop("f(lower) and f(upper) must have opposite signs")
  for (it in 1:max_iter) {
    mid <- (lower + upper) / 2; fm <- f(mid)
    if (abs(fm) < tol || (upper - lower) / 2 < tol)
      return(list(root = mid, value = fm, iter = it))
    if (fl * fm <= 0) { upper <- mid; fu <- fm }
    else              { lower <- mid; fl <- fm }
  }
  list(root = (lower + upper) / 2, value = f((lower + upper) / 2), iter = max_iter)
}
Newton-Raphson
newton_solve <- function(f, fp, x0, tol = 1e-8, max_iter = 1000, trace = FALSE) {
  x_old <- x0
  for (it in 1:max_iter) {
    x_new <- x_old - f(x_old) / fp(x_old)
    if (trace) cat(it, x_old, x_new, abs(x_new - x_old), "\n")
    if (abs(x_new - x_old) < tol) return(list(root = x_new, value = f(x_new), iter = it))
    x_old <- x_new
  }
  list(root = x_old, value = f(x_old), iter = max_iter)
}

7. EM 算法：em_norm2（两正态混合）

用途

给一堆数据，假设来自 $p\,N(\mu_1,\sigma_1^2)+(1-p)\,N(\mu_2,\sigma_2^2)$，估计 5 个参数。

E 步

$w_i = \dfrac{p\,\varphi(x_i;\mu_1,\sigma_1)}{p\,\varphi(x_i;\mu_1,\sigma_1) + (1-p)\,\varphi(x_i;\mu_2,\sigma_2)}$

M 步

$p \leftarrow \bar w,\; \mu_1 \leftarrow \dfrac{\sum w_i x_i}{\sum w_i},\; \sigma_1^2 \leftarrow \dfrac{\sum w_i (x_i-\mu_1)^2}{\sum w_i}$（$\mu_2,\sigma_2$ 对称用 $1-w_i$）

em_norm2 <- function(x, p = 0.5, mu1 = quantile(x, .25), mu2 = quantile(x, .75),
                     sd1 = sd(x), sd2 = sd(x), tol = 1e-8, max_iter = 1000) {
  loglik_old <- -Inf
  for (it in 1:max_iter) {
    # E step
    dens1 <- p * dnorm(x, mu1, sd1)
    dens2 <- (1 - p) * dnorm(x, mu2, sd2)
    w <- dens1 / (dens1 + dens2)
    # M step
    p <- mean(w)
    mu1 <- sum(w * x) / sum(w)
    mu2 <- sum((1 - w) * x) / sum(1 - w)
    sd1 <- sqrt(sum(w * (x - mu1)^2) / sum(w))
    sd2 <- sqrt(sum((1 - w) * (x - mu2)^2) / sum(1 - w))
    loglik <- sum(log(p * dnorm(x, mu1, sd1) + (1 - p) * dnorm(x, mu2, sd2)))
    if (abs(loglik - loglik_old) < tol) break
    loglik_old <- loglik
  }
  list(p = p, mu1 = mu1, mu2 = mu2, sd1 = sd1, sd2 = sd2, loglik = loglik, iter = it)
}
初值默认取 25%/75% 分位数；若数据强双峰可手工指定 mu1, mu2 让收敛更快。
